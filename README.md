# 🏋️ FitArc

**FitArc** is a modern fitness and nutrition tracking web application designed to help users monitor their fitness journey through an intuitive and interactive dashboard.

## ✨ Features

* 🏋️ Fitness & nutrition tracking
* 📊 Interactive progress charts
* 🎯 Personal fitness dashboard
* 📱 Responsive UI
* 🧭 Client-side navigation
* 🎨 Modern Tailwind CSS interface

## 🛠️ Tech Stack

* **React 18**
* **Vite**
* **Tailwind CSS**
* **React Router**
* **Recharts**
* **Lucide React**

The project uses React with Vite and includes Recharts for data visualization.

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/fitarc.git
cd fitarc
npm install
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
